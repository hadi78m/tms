## 1. Objective

یک جمله: **تحویل Web UI و گزارش پیشرفت برای مدل وزن/پیشرفت V1.8 (Modules → Stages →
Stage Approvals → WBS Checklist) که امروز فقط در DB و Domain وجود دارد.**

## 2. Candidate Next Capabilities (بدون انتخاب برنده)

### Candidate A — Module/Stage/Approval UI + Progress Report (بدون Migration)

- Description: صفحات Web برای CRUD ماژول/مرحله، ثبت/تأیید پیشرفت مرحله
  (تجمعی/جزئی)، WBS Phase/Checklist، و بازنویسی گزارش پیشرفت از
  `SUM(approved_amount)` روی stage approvals (جایگزینی TD-1).
- Readiness: **بالا** — services کامل، قواعد DB/Domain قطعی (DEC-034/037)،
  تست سرویس موجود؛ فقط لایهٔ HTTP/View + FormRequest + گزارش.
- Dependencies: فقط تصمیم UI scope؛ صفر schema.
- Decisions required: قاعدهٔ نمایش Tasks بدون stage در گزارش‌ها (گزارش‌گیری).
- Schema/UI/Test/Integration/Risk impact: صفر Migration · UI بزرگ · تست Feature
  جدید برای هر مسیر HTTP · صفر Integration · Risk کم (قواعد از قبل enforced در DB).

### Candidate B — Performance Record / per-contractor progress (نیازمند OQ-32)

- Description: فعال‌سازی `PerformanceRecordService` به‌عنوان Snapshot دوره‌ای
  per-contractor از تأییدهای Stage (OQ-32).
- Readiness: **متوسط** — سرویس اسکلت دارد ولی قاعدهٔ per-contractor تعریف‌نشده است.
- Decisions: **OQ-32 blocking** (شمارش stage approvals فاقد بعد پیمکار).
- Schema: احتمالاً صفر؛ Report: بله.

### Candidate C — Support Ledger / Financing

- Description: تفکیک مالی/گزارشی Support.
- Readiness: **پایین** — هیچ evidence الزامی در docs نیست (DEC-005 صراحتاً ledger
  مستقل را رد کرد)؛ نیازمند تصمیم کسب‌وکار جدید.
- Risk: بالاترین (مرز مالی/Integration).

## 9–14. Domain/Service/Auth/Audit/UI/Integration Plans

- Domain: صفر تغییر سرویس‌های موجود؛ فقط `ReportService` جدید (یا متد در
  ReportController) برای محاسبهٔ پیشرفت از `stage_progress_approvals`.
- Authorization: همان الگوی `role:` middleware + گاردهای سرویس؛ طبق ماتریس §۱۴
  گزارش reconnaissance (Supervisor: technical stage approval · Employer: نهایی/رؤیت).
- Audit: رویدادهای موجود کفایت می‌کنند (stage approval events از قبل ثبت می‌شوند)؛
  هیچ event جدیدی (طبق DEC-038).
- UI: صفحات جدید `modules/index|show`, `stages` (درون module show),
  `stage-approvals` (فرم ثبت/تأیید), `wbs-phases` (درون project show), checklist
  toggles, گزارش بازنویسی‌شده + CSV.
- Integration: صفر.
