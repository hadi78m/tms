# V1.11 — Decision Register

**قاعده:** `DR ≠ DEC` — DR پرسش است؛ DEC فقط پس از پاسخ صریح مالک ثبت می‌شود. شماره‌گذاری DEC از **DEC-048** (آخرین ثبت V1.10: DEC-047).
**تاریخ ثبت اولیه:** 2026-09-27 · **تاریخ اصلاح:** 2026-09-27 (تصحیح ثبت — DEC-049 کامل‌شده · DEC-050 رسماً ثبت شد · طبقه‌بندی نادرست «D-vs-E conflict» حذف شد).
**فاز:** Documentation / Decision-Registration Only — **صفر کد · صفر Migration · صفر Schema · صفر DB · صفر UI · صفر Test**.

> **اصلاحیهٔ ثبت (2026-09-27):** در ثبت قبلی دو خطای تفسیری وجود داشت: (۱) ترتیب migration در DR-11-2 به‌غلط «OPEN» ثبت شده بود، در حالی که گزینهٔ `D` خودِ ترتیب را تعریف می‌کند. (۲) DR-11-3 به‌غلط «CONFLICT» ثبت شده بود، در حالی که مالک صریحاً **گزینهٔ سفارشی E** را انتخاب کرده است. **هیچ DEC جدیدی ساخته نشد — شماره‌گذاری حفظ شد؛ DEC-050 از «RESERVED» به DEC رسمی تبدیل شد.**
