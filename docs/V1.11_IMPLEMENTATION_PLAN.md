## مرزهای Access (DEC-050 — الزام‌آور)

| ALLOWED | NOT ALLOWED در V1.11 |
|---|---|
| User → Role | Dynamic Route → Permission mapping |
| Role → Permission | ساخت Permission دلخواه از UI |
| User → Direct Permission | Deny / permission منفی |
| Effective = Role + Direct | override Business Invariants از طریق Permission |
| Grant-only | override Project Scope از طریق Permission |
| تغییرات auditable | override مرزهای مالی از طریق Permission |

کاتالوگ Permission **سیستم‌کنترل** · Policy = Resource Authorization · Service Guard = Business Invariants · **Project Scope مستقل از Permission**.
