| R1-09 | `InitialTmsSeeder` :164+ | هر ۳ تسک وزن صریح دارند |

### ۴.۲ Risks

- `SUM(weight)` ردیف NULL را بی‌صدا نادیده می‌گیرد ⇒ درصد نادرست بدون Exception.
- اما **هیچ مسیر فعال فعلی NULL تولید نمی‌کند** (وزن در HTTP `required` است؛ Seeder وزن صریح دارد) — ریسک شرطی بود، نه فعال.
- جانبی (شناسایی‌شده در Reconnaissance): با `weight = NULL`، CHECK `chk_wcr_weight_diff (new_weight <> old_weight)` در `WeightChangeRequest` همیشه UNKNOWN می‌شود.

### ۴.۳ Decision — `DEC-036` (مالک)

| سؤال | انتخاب |
|---|---|
| معنای NULL در گزارش | **R1-D — NULL در مسیر عادی ممنوع** (گزینه‌های A/B/C رد شدند) |
| weight در Create Task | **R1-F1 — اجباری می‌ماند** |

نتیجهٔ منطقی تصمیم: چون مسیر عادی هرگز NULL تولید نمی‌کند، رفتار `SUM`/CSV **صحیح باقی می‌ماند** و گزارش نیازی به تغییر ندارد. NULL فقط برای legacy/future import مجاز است و معنای آن در سند DEC-036 ثبت شد — نه «صفر»، نه «incomplete».
