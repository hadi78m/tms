Management: هیچ دسترسی مدیریتی فعلی. 6/7. Delegation: وجود ندارد. 8. Project Scope: هیچ (بند ۳). 9. Audit Visibility: role-based هاردکد (`role:supervisor|employer` — طبق DEC-045). 10. **Invariants غیرقابل-override از UI:** SUM(stage weights)=100 · Approval ceiling · immutability/supersede chain · DEC-043 terminal lock · DEC-040 aggregation rule · مرز مالی DEC-041.
