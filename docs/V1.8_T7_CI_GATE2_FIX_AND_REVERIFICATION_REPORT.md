## 2. Observed Failure (run 35830322842)

Gate 2 بدون هیچ پیام خطایی با `exit 1` قطع شد — در حالی که همان لاگ ۳۲ ردیف
`[1] Ran` و صفر `Pending` را نشان می‌داد.

## 3. Root Cause (دو لایه)

**لایهٔ ۱ (اصلی):** زیر `bash -e -o pipefail`، وقتی `grep -c` **صفر match** می‌یابد
(exit 1 — یعنی همان «0 Pending» که می‌خواهیم)، assignment سالم کل step را بی‌صدا
می‌کُشد. `|| true` فقط در همین محدودهٔ zero-match اضافه شد (مجاز طبق §۵).

**لایهٔ ۲ (کشف محلی):** بازتولید دقیق منطق gate در bash محلی نشان داد خروجی
`migrate:status` حتی در CI حاوی **ANSI color codes و `\r`** است؛ الگوی قبلی شکننده
بود. count حالا پس از strip کنترل‌کاراکترها انجام می‌شود.

## 4. Exact Fix (فقط `.github/workflows/ci.yml`)

```yaml
RAN=$(printf %s "$CLEAN" | grep -cE '] *Ran'     || true)   # zero-match = نتیجهٔ معتبر
PENDING=$(printf %s "$CLEAN" | grep -cE '] *Pending' || true)
# CLEAN = status با حذف \r و ANSI escape codes
# assertions بعدی دست‌نخورده: PENDING != 0 → exit 1 · RAN != 32 → exit 1 (fail-closed)
```
