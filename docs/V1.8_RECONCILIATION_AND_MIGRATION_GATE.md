### سه پرسشی که برای باز شدن قفل لازم است

**۱️⃣ OQ-01a — آیا Module سهم وزنی از Project دارد؟**

```text
(الف) بله — هر Module یک weight دارد (مثال: Module A = 40%, B = 35%, C = 25%)
      → ستون modules.weight NUMERIC(5,2) NOT NULL در Schema می‌آید

(ب) خیر — Module وزن ندارد؛ فقط Stageها وزن دارند (هر Module مستقلاً 100%)
      → ستون weight در modules حذف می‌شود و همهٔ ماژول‌ها هم‌وزن‌اند
```

**۲️⃣ OQ-04 — آیا هر Task الزاماً به یک Module Stage وصل می‌شود؟**

```text
(الف) بله، اتصال اجباری است
      → tasks.module_stage_id BIGINT NOT NULL
      → task_type لازم نیست (نوع از stage_code استنتاج می‌شود)
      ⚠️ تسک‌های موجود باید Backfill شوند؛ تسک اداری بدون Stage جایی ندارد

(ب) خیر، اتصال اختیاری است
      → tasks.module_stage_id BIGINT NULL
      → task_type لازم است تا نوع Support/Development مشخص بماند
      ✅ سازگار با وضع موجود (wbs_phase_id هم NULLABLE است)
```

**۳️⃣ OQ-05 (جدید) — آیا وزن پایهٔ Stage پس از ثبت تأیید قابل تغییر است؟**

```text
(الف) پس از اولین تأیید، وزن پایه قفل می‌شود   ← پیشنهاد ما
      → no snapshot needed — Schema ساده‌تر
      → «۱۲ از ۱۵» همیشه معنای یکسان دارد

(ب) قابل تغییر است
      → هر رکورد تأیید باید وزن پایه را Snapshot کند
      → Schema یک ستون بیشتر + منطق محاسبهٔ پیچیده‌تر
```
