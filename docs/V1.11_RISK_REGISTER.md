## کنترل‌های تأییدشدهٔ Settings & Access (DEC-050)

- Permission Catalog **سیستم‌کنترل** است.
- Direct User Permissions **فقط Grant** هستند.
- **صفر Deny model** در V1.11.
- **صفر Dynamic Route → Permission mapping**.
- Business Invariants **از طریق Permission قابل override نیستند**.
- Project Scope **مستقل از Permission** است.
- Access changes **باید auditable** باشند.
