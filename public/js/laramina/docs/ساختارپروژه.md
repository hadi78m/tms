## ساختار ماژول ساخته شده توسط آرتیسان

### دستور ایجاد ماژول

```bash
php artisan admin:make-ui Sms\Provider
```
### ساختار ایجاد شده 

```text
js/
└─ modules/
     └─ name1(sms)/
        └─ name2(providers)
           ├─ forms/
           │   ├─ otherForm.js
           │   └─ create-form.js
           ├─ table.js
           ├─ actions.js
           └─ module.js
```
