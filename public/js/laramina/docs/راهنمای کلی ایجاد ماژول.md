## چند روش تعریف اکشن

### ✔ نمونه 1 — اکشن ساده فقط handler

```javascript
edit: (row) => {
    console.log('edit', row)
}

```
### ✔ نمونه 2 — function + metadata (ساده و تمیز)

```javascript
edit: Object.assign(
    (row, table) => {
        console.log('edit', row)
    },
    {
        icon: 'fas fa-edit',
        color: 'text-blue-600',
        tooltip: 'ویرایش'
    }
)

```
### ✔ نمونه 3 — اکشن با Action Builder (پیشنهادی – بهترین روش)
```javascript
import { action } from '../core/action.js'

edit: action({
    icon: 'fas fa-edit',
    color: 'text-blue-600',
    tooltip: 'ویرایش',
}, (row, table, event) => {

    const url = AppAlert.route(createForm.updateEndpoint, { id: row.id })
    event?.preventDefault()

    ModalPlugin.open({
        title: 'ویرایش پرووایدر',
        width: '500px',
        content: (container) => {

            const config = {
                ...createForm,
                endpoint: url,
                method: 'PUT'
            }

            FormEngine.render(config, container, row)
        }
    })
})
```

### ✔ نمونه 4 — اکشن با confirm

```javascript
delete: action({
    icon: 'fas fa-trash',
    color: 'text-red-600',
    tooltip: 'حذف',
    confirm: 'آیا مطمئن هستید؟'
}, async (row, table) => {

    await fetch(`/api/delete/${row.id}`, { method: 'DELETE' })
    table.removeRow(row.id)
})
```
### ✔ نمونه 5 — اکشن object-based (روش رسمی قبلی)



```javascript
status: {
    icon: 'fas fa-toggle-on',
    color: 'text-green-600',
    tooltip: 'تغییر وضعیت',
    handler(row, table) {
        console.log('status', row)
    }
}
```

### ✔ نمونه 6 — اکشن با disable condition

#### ( برای آینده کاملاً سازگار است )

```javascript
    console.log('ban', row)
})
```
